# Настройка параметров ArduPilot для GUIDED + GPS_INPUT

## Обязательные параметры (установить ДО полёта)

### 1. GPS_TYPE2 = 14 (MAV)
Второй GPS-слот принимает данные по MAVLink (GPS_INPUT сообщение).
Через этот слот мы отправляем позицию от Dead Reckoning при потере основного GPS.

**ВАЖНО: требует РЕБУТ после изменения!**

```
GPS2_TYPE = 14
```

Уже установлено в `default.param`.

### 2. GPS_AUTO_SWITCH = 1
Автоматическое переключение на лучший GPS-источник.
Когда основной GPS пропадёт, ArduPilot переключится на наш GPS_INPUT.

```
GPS_AUTO_SWITCH = 1
```

Уже установлено в `default.param`.

### 3. GPS_PRIMARY = 0
Основной GPS = первый (аппаратный). Второй (наш GPS_INPUT) используется как резервный.

```
GPS_PRIMARY = 0
```

Уже установлено в `default.param`.

## Параметры EKF3 (источники данных)

Текущая конфигурация EK3_SRC1 использует GPS для позиции и скорости:

```
EK3_SRC1_POSXY = 3   (GPS)
EK3_SRC1_POSZ  = 1   (Baro)
EK3_SRC1_VELXY = 3   (GPS)
EK3_SRC1_VELZ  = 3   (GPS)
EK3_SRC1_YAW   = 1   (Compass)
```

Это правильно. EKF3 будет автоматически использовать GPS_INPUT как второй GPS
когда основной пропадёт (благодаря GPS_AUTO_SWITCH=1).

**Не нужно менять EK3_SRC параметры** - переключение GPS происходит на уровне
GPS драйвера, а не EKF source switching.

## Параметры Q_ASSIST (защита от срабатывания коптерных моторов)

Текущие значения:
```
Q_ASSIST_SPEED   = 18    (м/с - скорость ниже которой включаются копт. моторы)
Q_ASSIST_ANGLE   = 30    (градусы крена/тангажа)
Q_ASSIST_DELAY   = 0.5   (секунды задержки перед включением)
Q_ASSIST_ALT     = 0     (отключено по высоте)
Q_ASSIST_OPTIONS = 0
```

### Проблема
При переключении с реального GPS на GPS_INPUT скорость может кратковременно
упасть до 0 в EKF. Если скорость < Q_ASSIST_SPEED (18 м/с) — включатся
коптерные моторы.

### Защита в коде (уже реализована)
1. **Velocity всегда заполняется** в GPS_INPUT (vn/ve/vd из groundspeed+heading)
2. **Прогрев GPS_INPUT** — шлём GPS_INPUT с низким приоритетом (horiz_accuracy=50)
   даже при работающем GPS, чтобы EKF знал про источник заранее
3. **Стабильная частота** — GPS_INPUT шлётся каждые ~200мс (5 Гц)

### Дополнительная защита в параметрах (рекомендуется)

Если Q_ASSIST всё равно срабатывает при тестировании, можно:

**Вариант А: Увеличить задержку Q_ASSIST**
```
Q_ASSIST_DELAY = 1.5
```
Даёт больше времени на стабилизацию при переключении GPS.

**Вариант Б: Уменьшить порог скорости**
```
Q_ASSIST_SPEED = 12
```
Нормальный полёт на 18-20 м/с, так что порог 12 м/с оставляет больший запас.

**Вариант В: Отключить Q_ASSIST по скорости (только для тестирования!)**
```
Q_ASSIST_SPEED = 0
```
НЕ для реального полёта! Только для отладки GPS_INPUT в SITL.

## Параметры GUIDED режима

Текущие значения PID для GUIDED heading tracking:
```
GUIDED_P    = 5000   (пропорциональный)
GUIDED_I    = 0      (интегральный)
GUIDED_D    = 0      (дифференциальный)
GUIDED_FF   = 0      (feed-forward)
GUIDED_IMAX = 10
GUIDED_SMAX = 0
```

Дефолтные значения должны работать для SITL.
Если самолёт плохо отслеживает курс к целевой точке — подкрутить GUIDED_P.

## Как загрузить параметры

### В SITL (Mission Planner):
1. Подключиться к SITL
2. Config/Tuning -> Full Parameter List
3. Загрузить файл `default.param` через "Load from file"
4. Нажать "Write Params"
5. **Перезагрузить SITL** (GPS2_TYPE требует ребут)

### В SITL (MAVProxy):
```
param load default.param
reboot
```

### Проверка что GPS2 работает:
В Mission Planner -> Status tab -> смотреть `gps2_status`:
- До нашего GPS_INPUT: `gps2_status = 0` (нет данных)
- После engage (прогрев): `gps2_status = 3` (3D fix от нашего GPS_INPUT)
- При потере GPS1: ArduPilot переключится на GPS2 автоматически
